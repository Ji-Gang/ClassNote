# 课程便笺 ClassNote

Windows 桌面课程便笺与离线课表 CSV 生成器。支持按日期记录课堂内容、待办管理、独立滚动、窗口缩放、置顶和课后提醒。

## 启动便笺

本地双击 `ClassNote.exe` 或“课后小记”快捷方式，无命令行窗口。源码下载后首次双击 `Start.cmd`，会编译 GUI 启动器再启动，之后直接打开 `ClassNote.exe`。需要 Windows 自带的 Windows PowerShell 5.1 和 Windows Forms，无需 Node 或 Python。首次启动使用示例课程。关闭窗口收起到系统托盘，通过菜单“退出”结束程序。

## 生成自己的课表

双击 `generator/index.html`，用浏览器打开：

1. 填写学期第 1 周周一，以及学校每节课实际起止时间。
2. 添加课程，选择星期和起止节次，填写周次，如 `1-16`、`2-16双周`、`1-15单周`、`3,7,11,15`。
3. 生成预览，核对日期；可删除停课日期、添加补课或修改单节课程时间。
4. 下载 CSV，在便笺右下角菜单选择“导入课表”。

配置可以保存成 JSON，下次读取后继续编辑。生成器不发送数据到服务器，不自动连接教务系统。学校临时调课需要手动调整。

CSV 格式为 `date,course,start,end`；日期 `YYYY-MM-DD`，时间 `HH:mm`。导入会替换课表，保留笔记与待办。

## 提醒

- **自动下课提醒已实现**：导入带有有效起止时间的真实 CSV 后，程序运行期间每秒检查当天已结束且未记录的课程。
- **手动延迟提醒已实现**：点击“10 分钟后提醒”，到期出现独立提醒卡片。
- 只有节次、没有钟点时间的课表不会触发自动下课提醒，需先补齐时间。
- 不会在关机或退出程序后后台运行；没有开机自启。重新启动会补提醒当天符合条件的课程和已到期的手动提醒。

## 笔记和待办

双击课程后选择日期。今天的课程日期保留；过去只显示有内容的记录，未来日期隐藏。草稿自动保存。待办点击圆圈完成，点击文字显示删除按钮。各窗口可拖动边缘缩放。

## 本地数据与隐私

`data.json` 保存笔记、待办、课表和设置；`data.backup.json` 保留上一版。可选的 `timetable-rules.json` 保存个人学期规则。上述文件、日志、导出 CSV 和机器专用快捷方式均通过 `.gitignore` 排除，不应上传到仓库。

## 开发检查

生成器逻辑测试（仅开发时需要 Node）：

```sh
node generator/test.cjs
```

主程序入口为 `Desktop.ps1`，启动包装为 `Launch.ps1`。`Timetable.ps1` 支持将本地教学周规则展开成日期。项目没有学校账户登录或在线课表同步功能。
## 托盘运行
运行时只显示系统托盘图标。左键点击图标恢复窗口，右键菜单选择退出才结束程序。关闭便笺只隐藏窗口，不退出托盘。图标是否折叠在小三角内由 Windows 设置决定。

## 示例发布版
此副本仅含虚构示例课程，不含个人课表、笔记、待办、日志或原仓库历史。首次启动展示示例课程。可在生成器中读取 timetable-rules.example.json，或复制并改名为 timetable-rules.json 后使用本地周次规则。示例时间和日期仅供演示，请按实际课表修改。
日期档案只列出有内容的课程，双击打开当天记录的只读预览。
